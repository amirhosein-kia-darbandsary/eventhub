# ADR-000X: Use uv Instead of Poetry

## Status

Accepted

## Context

The project requires a modern Python package and dependency manager that provides fast dependency resolution, virtual environment management, and reproducible builds. While Poetry is a mature and widely adopted tool, `uv` offers significantly better performance because it is implemented in Rust. It also provides compatibility with the Python packaging standards (`pyproject.toml`) while simplifying common development workflows.

## Decision

The project will use **uv** as the standard tool for:

* Managing project dependencies
* Creating and managing virtual environments
* Installing and synchronizing packages
* Locking dependency versions using `uv.lock`

All contributors should use `uv` instead of Poetry for local development and CI/CD pipelines.

## Alternatives Considered

| Option         | Advantages                                                                         | Disadvantages                                 |
| -------------- | ---------------------------------------------------------------------------------- | --------------------------------------------- |
| **uv**         | Extremely fast, written in Rust, compatible with `pyproject.toml`, modern workflow | Newer ecosystem, fewer tutorials than Poetry  |
| **Poetry**     | Mature ecosystem, widely adopted, excellent packaging support                      | Slower dependency resolution and installation |
| **pip + venv** | Standard Python tools, available everywhere                                        | No dependency locking, more manual workflow   |

## Consequences

### Positive

* Faster dependency installation and resolution.
* Consistent environments through `uv.lock`.
* Simpler developer onboarding.
* Reduced CI/CD execution time.
* Uses modern Python packaging standards.

### Negative / Risks

* Team members must become familiar with `uv`.
* Some existing documentation and tutorials assume Poetry.
* The ecosystem is newer than Poetry, so some workflows may be less documented.
